# Open Grok v1.0.0-open-grok.82

This `megascan/open-grok` release starts new sessions inside the workspace
sandbox by default, includes selected Grok Build 1.0.6 snapshot improvements,
adds live OpenRouter inference, and opts Codex GPT-5.6 into a larger context
window. Installers and in-app updates resolve GitHub Releases from this
repository.

- Protect the host filesystem by restricting agent writes to the active
  workspace, Open Grok state, and temporary directories unless sandboxing is
  explicitly disabled. Existing configuration, managed requirements, and
  resumed-session sandbox profiles continue to take precedence.
- Add browser-style prompt selection and clipboard editing, including shifted
  word and line navigation, Command-C/Command-X, selection replacement, and
  single-step undo.
- Show securely validated MCP server and tool icons through the agent-client
  protocol while rejecting unsafe icon sources and bounding icon metadata.
- Preserve authentic runtime identity and plugin-owned variables in command and
  HTTP hooks, including values interpolated into hook URLs.
- Resolve repository HEAD directly from Git references so large or damaged
  commit packs no longer prevent session startup, status, or file watching.
- Restore web-search, X-search, and Codex permission regression fixtures.

## OpenRouter

- OpenRouter is a first-class provider with live model discovery and
  advertised reasoning efforts.
- Configure its API key from Settings or `/login openrouter`, or set
  `OPENROUTER_API_KEY`. Attribution headers identify this repository.

## Codex GPT-5.6 context window

- Unset keeps the product-tuned catalog default (~353K effective).
- Opt into the published ~1.05M raw window with Codex-compatible keys:

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

- Per-model `[model.*] context_window` still wins. xAI and other providers
  are unchanged.

## Install and updates

Installers, `open-grok update`, and launch auto-update now resolve GitHub
Releases from `megascan/open-grok` instead of `mweinbach/open-grok`.

```powershell
irm https://github.com/megascan/open-grok/releases/latest/download/install.ps1 | iex
open-grok --version
```

```sh
curl -fsSL https://github.com/megascan/open-grok/releases/latest/download/install.sh | bash
open-grok --version
```
